# Mash X-Ride 125

## Rôle dans le vault

Cette note centralise les sujets liés à la Mash X-Ride 125 : entretien, équipement, améliorations trail, alimentation électrique et transport de matériel.

## Usage recherché

La moto est utilisée comme base polyvalente route / balade / trail léger. Les modifications doivent rester simples, réversibles et compatibles avec une 125 légère.

## Améliorations envisagées

- [[Améliorations trail X-Ride]]
- crash-bars / pare-carter ;
- repose-pieds type enduro ;
- rehausse de guidon ;
- sacoches souples ;
- alimentation USB pour téléphone / navigation ;
- solutions de transport pour matériel volumineux.

## Entretien

Créer une entrée datée dans le journal à chaque révision ou intervention importante, avec : kilométrage, opération, pièces, coût et garage.

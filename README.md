# Obsidian Vault

Vault personnel centralisant projets, documentation technique, connaissances, idées et suivi.

## Structure

- `00 - Inbox` : capture rapide de notes à trier.
- `01 - Dashboard` : page d'accueil du vault.
- `10 - Projects` : projets avec objectif et état d'avancement.
- `20 - Areas` : domaines suivis dans la durée.
- `30 - Knowledge` : connaissances réutilisables.
- `40 - Resources` : ressources et références.
- `50 - Journal` : notes quotidiennes et journal de travail.
- `90 - Templates` : modèles de notes.
- `99 - Archives` : contenus terminés ou obsolètes.

## Principe

GitHub reste la source de vérité pour le code des projets. Ce vault sert à documenter les décisions, l'architecture, les recherches, les procédures, les idées et le suivi personnel.

## Règle de maintenance

Pour les projets liés à un dépôt GitHub, le dépôt reste la source de vérité pour l'état du code. Les notes Obsidian servent à conserver :

- l'architecture ;
- les décisions ;
- les explications ;
- les procédures ;
- les connaissances réutilisables ;
- le contexte difficile à retrouver dans le code seul.

Quand une information dépend d'une branche, préciser explicitement la branche concernée.
